# Lead Manager

A small full-stack web app for a sales user to capture and track leads.

> Work in progress. This README is completed at the end of the build.

## Planned stack

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB (Mongoose)
- **Validation:** Zod (frontend and backend)
- **Auth:** JWT (signup / login, each user sees only their own leads)
- **Tests:** Jest and Supertest

## Planned features

- Add, list, edit and delete leads (delete asks for confirmation)
- Search and filter by name or status
- Input validation on both frontend and backend
- Signup / login with per-user data
- Dashboard with lead counts per status
- Automated API tests
